MINKA VOZ — Windows
====================

Traductor de voz Kogui <-> Español para Windows. 100% offline.

INSTALACION RAPIDA
--------------------
1. Descarga "MINKA VOZ.exe" de la carpeta dist/
2. Haz doble clic -- no requiere instalacion

USO
---
- MANTEN PRESIONADO el microfono (icono azul) y habla
- SUELTA para transcribir y traducir
- Cambia direccion con el boton "Kogui -> Espanol / Espanol -> Kogui"
- Diccionario: busca, agrega, edita o elimina palabras
- Historial: ve tus traducciones recientes
- Modo oscuro: boton de luna en la esquina

REQUISITOS
----------
- Windows 10/11 (64-bit)
- Microfono funcional

TRADUCCION
----------
Usa diccionario local SQLite (~108 palabras base Kogui).
Si la frase no esta completa, traduce palabra por palabra
y marca lo no encontrado con [corchetes].

SOLUCION DE PROBLEMAS
---------------------
Problema                    Solucion
"No se entiende"            Habla mas fuerte, mas cerca del microfono, al menos 1 segundo
Error de audio al reproducir  Reinstala el .exe (a veces falla la primera vez por SDL)
Ventana no aparece          Verifica que no este minimizada en la barra de tareas
