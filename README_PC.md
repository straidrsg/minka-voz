# MINKA VOZ — Windows

Traductor de voz Kogui ↔ Español para Windows. 100% offline.

## Instalación rápida

1. Descarga `MINKA VOZ.exe` de la carpeta `dist/`
2. Haz doble clic — no requiere instalación

## Uso

- **Mantén presionado el micrófono** (ícono azul) y habla
- **Suelta** para transcribir y traducir
- Cambia dirección con el botón **Kogui → Español / Español → Kogui**
- **Diccionario**: busca, agrega, edita o elimina palabras
- **Historial**: ve tus traducciones recientes
- **Modo oscuro**: botón 🌙 en la esquina

## Requisitos

- Windows 10/11 (64-bit)
- Micrófono funcional

## Traducción

Usa diccionario local SQLite (~108 palabras base Kogui). Si la frase no está completa, traduce palabra por palabra y marca lo no encontrado con `[corchetes]`.

## Solución de problemas

| Problema | Solución |
|----------|----------|
| "No se entiende" | Habla más fuerte, más cerca del micrófono, al menos 1 segundo |
| Error de audio al reproducir | Reinstala el .exe (a veces falla la primera vez por SDL) |
| Ventana no aparece | Verifica que no esté minimizada en la barra de tareas |
